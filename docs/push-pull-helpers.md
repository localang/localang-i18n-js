# Push/Pull Helpers

> ⚠️ **Deprecated.** The `push` and `pull` helpers synchronized translations with the
> hosted Localang service, which has been **discontinued**. They no longer have a working
> backend and are kept for reference only. The i18n library and the
> [ESLint plugin](./i18n-file-generator.md) remain fully usable without them.

To automate translation synchronization between the hosted service and your codebase, you could use special helpers to upload and download translations.

## Push

You could use `push` to upload translations.

```javascript
import { push } from 'localang-i18n-js';

/** @type {string} */
const authToken = 'your-auth-token';
/** @type {number} */
const projectId = 1;
/**
 * Files with translations must be generated by the ESLint plugin
 * (see ./i18n-file-generator.md).
 * @type {string[]}
 */
const files = [
    'src/index.i18n.ts',
    'src/components/Header.i18n.ts',
    'src/components/Footer.i18n.ts',
];

push(authToken, projectId, files);
```

## Pull

You could use `pull` to download translations. The helper loaded the translations and updated the local files relative to the project root.

```javascript
import { pull } from 'localang-i18n-js';

/** @type {string} */
const authToken = 'your-auth-token';
/** @type {number} */
const projectId = 1;

pull(authToken, projectId);
```
