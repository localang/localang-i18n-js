# Localang

[![Continuous Integrations](https://github.com/pavelpilyak/localang-i18n-js/actions/workflows/continuous-integrations.yaml/badge.svg?branch=main)](https://github.com/pavelpilyak/localang-i18n-js/actions/workflows/continuous-integrations.yaml)

This is a localization toolkit:
1. I18n JS library
2. ESLint plugin for automatic generation of files with translations

> **Note:** Localang previously offered a hosted service for translators, managers and
> non-developers, together with ready-made Github Actions and `push`/`pull` helpers to
> synchronize translations between that service and your code. **The hosted service has
> been discontinued**, so those sync helpers and Actions are deprecated and no longer
> functional. The library and the ESLint plugin remain fully usable on their own.

See [documentation](./docs/getting-started.md).

![Example](readme-example.gif)

## Installation

This library is published in the NPM registry and can be installed using any compatible package manager.

```sh
npm install localang-i18n-js --save

# For Yarn, use the command below.
yarn add localang-i18n-js
```
